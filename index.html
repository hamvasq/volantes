How printing works

Bluetooth talks straight to the printer from Chrome on Android. The page must be opened from an https:// address, and the printer must support Bluetooth LE (most 58 mm ESC/POS printers do).

RawBT hands the slip to the RawBT app on Android, which also handles classic-Bluetooth printers.

System print uses the phone's print dialog, for printers with an Android print plugin.
